# docs/

Working documents for MSEDB. The **root** files are the standard, authoritative
set — start there:

| Root file | What it owns |
|---|---|
| `CLAUDE.md` | Commands, architecture, ports, gotchas (agent front door) |
| `README.md` | Human front door |
| `DEPLOY.md` | Deploy + rollback procedure |
| `RUNBOOK.md` | Logs, restarts, common failures |
| `stack.md` | Definitive tech stack (from lockfiles) |
| `data.md` | DB engine, environments, sync direction, DB change log |
| `backup.md` | Backup + restore, schedule, restore-test log |
| `design.md` | UI direction |
| `MEMORY.md` | Session learnings |

Everything in this directory is supporting material: reviews, plans, reports and
one-off analyses. `docs/adr/` holds architecture decision records.
