# Architecture Decision Records

One `ADR-NNNN.md` per decision, numbered sequentially and never renumbered.

Each record states: **Context** (what forced a decision), **Decision** (what was
chosen), **Consequences** (what this makes easy and what it makes hard), and
**Status** (Proposed / Accepted / Superseded by ADR-NNNN).

Records are append-only — supersede, don't rewrite.
